## Quick Start

### Prerequisites

- [Hugo Extended](https://gohugo.io/installation/) ≥ 0.120
- Git

### Run Locally

```bash
# Clone the repository
git clone --recursive \
  https://github.com/SalauddinAhmad/tech-blog-en.git
cd tech-blog-en

# Start development server
hugo server -D
```

Open `http://localhost:1313` in your browser.

### Build

```bash
hugo --minify
```

Static output is generated in the `public/` directory.
