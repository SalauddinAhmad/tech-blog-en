# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | ✅        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately:

1. Email `security@salaudinahmad.com` with the subject line **"[Security] Tech Blog Vulnerability"**.
2. Include a description of the vulnerability, affected component, and steps to reproduce (if possible).
3. We will acknowledge receipt within 48 hours and work with you on a fix and disclosure timeline.

We appreciate responsible disclosure and will credit researchers who report issues.

## Policy

- We follow [Coordinated Disclosure](https://en.wikipedia.org/wiki/Coordinated_vulnerability_disclosure).
- Do not exploit the vulnerability or access data beyond what is needed to demonstrate the issue.
- Do not share the vulnerability with others until it has been resolved and disclosed.
